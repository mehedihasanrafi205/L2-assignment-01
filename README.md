## 🛠️ Problems Solved

Here is a summary of the problems addressed in `solutions.ts`:

1.  **Filter Even Numbers**: A function to filter even numbers from an array.
2.  **Reverse String**: A function that reverses a given string.
3.  **Type Checker**: Uses Union types and `typeof` operator for type narrowing.
4.  **Generic Property Getter**: A generic function to safely retrieve a property from an object using `keyof`.
5.  **Book Status Toggle**: Uses Interface and Intersection types to update object properties.
6.  **Inheritance in OOP**: Demonstrates Class inheritance with `Person` and `Student` classes.
7.  **Array Intersection**: A function to find common elements between two arrays of numbers.

## ✍️ Blogs Overview

### 1. Why `unknown` is Better Than `any`
This blog covers the risks of using the `any` type and explains how `unknown` provides better type safety when combined with **Type Narrowing**.

### 2. Understanding TypeScript Generics
This blog explains how **Generics** act as type placeholders to create reusable and flexible code without losing type information.
